Friends beta · @VERSION@ (@BUILD@) · Apple silicon · macOS 15 or later

This is a beta. Keep a separate copy of important recordings. AI can omit words or invent details. Check important answers against the original source.

Install

  1. Open the disk image.
  2. Drag DropSift to Applications.
  3. Eject the disk image. Open DropSift from Applications.

Use only the signed, notarized build supplied by the sender. If macOS reports an unidentified developer, a damaged app, or a revoked signature, stop and ask the sender for a verified build. Do not disable Gatekeeper or remove quarantine flags to make it run.

Start small

  1. In Settings, start with Apple native and the default Qwen3.5 2B model. Larger models need more memory and disk space.
  2. Add a short note in Capture. Find it in Timeline.
  3. While online, make a short test recording. The speech models download on first use.
  4. Play the recording. Check both the audio and the transcript.
  5. Ask a simple question with an answer in your note or recording. The first AI question may need a separate model download.

Downloads can take several minutes and need several GB of free space. Model loading, transcription, and AI generation use CPU, GPU, and memory. No cloud inference account is needed.

Recording permissions

macOS asks for microphone and system-audio access when needed. If you deny access, you can still use notes, imports, Timeline, and Ask.

  • For your voice: System Settings → Privacy & Security → Microphone.
  • For the other side of a call: Privacy & Security → Screen & System Audio Recording.
  • System audio can include music, notifications, and other apps. Check the live microphone and system indicators.
  • Get permission from participants before recording. Stop recording yourself when the call ends. Meeting detection is a heuristic, not a guarantee.

Your files

The default library is iCloud Drive/DropSift when iCloud Drive is available. Otherwise DropSift uses a local library. Settings shows the exact location. Recordings, notes, transcripts, and conversations can sync through your own iCloud account.

Sync is not a separate backup. Deletions can propagate to other devices. Removing the app does not automatically remove your library or downloaded models.

Known limits

  • This build requires an Apple-silicon Mac. It does not support Intel Macs.
  • Only an M4 Max development Mac has been tested in this release run. Older Macs and macOS 15 need separate device validation.
  • Native transcription is recommended for important long recordings. QVAC is an advanced beta option. Tests found phrase omissions on some long composite samples.
  • TranscribePsy remains experimental and is not the app's default transcription model.
  • Speaker names, summaries, titles, tasks, and dates can be wrong. Review them before use.
  • There is no automatic app updater. Install a newer signed build over the app in Applications.
